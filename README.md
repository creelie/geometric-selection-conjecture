# Explicit String Vacua and the Geometric Selection Conjecture

Deep Bhattacharjee and Ushashi Bhattacharya.

Version **2.0.0** is a research revision with Annals-format and
Hexagon-format review manuscripts, independent construction controls and
an explicit nine-condition proof ledger.

**The full GSC remains unproved. No vacuum satisfying all nine conditions
has been constructed.** The local effective model has not been realized
by the compactification. No Annals-level novelty or acceptance is claimed.

The geometric example is credited to Buchbinder, Constantin and Lukas
(JHEP 03 (2014) 025). The draft gives its Chern/slope/index checks,
an invariant-family construction, normalization bounds, a quantitative
minimum criterion, and a local effective-theory example with its missing
string realization stated explicitly. These criteria are not claimed as
new breakthrough theorems. The mathematical body is identical in both
editions; neither PDF has margin line numbers.

The previous mirror-clause note remains under `paper/` and in the v1
release tags. The Dwork article is a separate cited paper. The proposed
Hexagon revision is to [2610.00493v1](https://hexagonmath.org/2610.00493v1);
no public v2 upload has been performed. New author review is pending.

The original Python mirror-clause check is retained. New exact controls
run with Python 3 and symbolic controls with Sympy 1.14.0. See the package
verification files and source folders for reproduction instructions.
